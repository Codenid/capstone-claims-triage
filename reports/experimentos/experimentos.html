6 · Cómo reproducir

uv sync --frozen
uv run dvc pull                                   # datos y modelos desde DagsHub (pide acceso)
uv run dvc repro                                  # P1–P6: de crudo a tabla preparada
uv run python -m src.evaluation.comparison_table  # regenera comparacion_modelos.csv desde reports/modeling/
uv run --no-sync python scripts/export_mlflow_runs.py   # exporta las corridas de MLflow (credenciales)
cd reports/experimentos && quarto render          # esta página

Los modelos se entrenaron en el clúster Khipu con los jobs de scripts/hpc/; cada carpeta de reports/modeling/ guarda la regla fijada antes de correr (decision.md), los diagnósticos y las métricas de cada corrida. El informe completo está en reports/informe/informe.pdf.
